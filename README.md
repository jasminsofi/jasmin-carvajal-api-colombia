# Mini Portal de Colombia con API
Jasmin Sofia Carvajal Prada


## Descripción
Aplicación web informativa sobre Colombia desarrollada con HTML5, CSS3 y JavaScript puro (Vanilla JS) que consume datos en tiempo real desde la API pública [API Colombia](https://api-colombia.com/). El portal cuenta con dos vistas conectadas mediante hipervínculos:
1. **Explorador de Departamentos:** Muestra los 33 departamentos/distritos de Colombia con su región, población, superficie, descripción y un conteo dinámico de departamentos por región.
2. **Sabores de Colombia:** Presenta el catálogo de platos típicos colombianos con su departamento de origen, descripción, fotografía (con manejo de imágenes de respaldo) y contador total de platos.

## Tecnologías usadas
* **HTML5:** Estructura semántica multipágina.
* **CSS3:** Diseño responsivo mediante CSS Grid, Flexbox y variables CSS.
* **JavaScript (ES6+):** Consumo de API REST con `fetch`, manipulación dinámica del DOM, indicadores de carga y manejo de errores con `.catch()`.
